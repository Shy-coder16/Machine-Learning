# Machine-Learning
In this project, I have developed a machine learning–based system PULS that can predict whether a person has a risk of heart disease or not by using some important medical information such as age, blood pressure, cholesterol level, chest pain type, and other health parameters.
For this prediction, I used a supervised machine learning algorithm called Logistic Regression, which is suitable for yes/no type classification. The model is trained using a real medical dataset and its performance is checked using accuracy score, confusion matrix, and classification report. This project shows how machine learning can be helpful in early detection of heart disease using patient data.
